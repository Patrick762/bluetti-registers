The Modbus-TCP protocol, other than the bluetooth protocol, has been published by Bluetti on [GitHub](https://github.com/bluetti-official/bluetti-modbus-tcp-slave) as an Excel Table.
This protocol was introduced with the Balco series of devices and has since been implemented for some powerstations as well.
Since it uses Modbus-TCP it can only be used on devices with a wifi chip, which not all Bluetti devices have.
